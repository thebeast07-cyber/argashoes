# Catatan implementasi

Folder ini isinya catatan per tahap: apa yang dibangun, file mana saja, alurnya, cara ngetes, dan keputusan yang diambil. Spesifikasi produknya tetap di `docs/PRD.md`.

| File | Isi |
|---|---|
| [01-fondasi.md](01-fondasi.md) | Tahap 1: kerangka Next.js, database, login admin, skema, fungsi fee & status order |
| [02-antislop.md](02-antislop.md) | Aturan anti-slop yang dibaca tiap sesi: isi, cara kerja, cara update |
| [03-produk-stok.md](03-produk-stok.md) | Tahap 2: produk, size, stok, Tandai habis, import/ekspor CSV |
| [roadmap.md](roadmap.md) | Urutan tahap berikutnya dan apa yang perlu ditanya ke retailer |

Aturan: setiap tahap baru dapat file sendiri (`02-...md`, `03-...md`) dan baris baru di tabel ini.
